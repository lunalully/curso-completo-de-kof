## Como estudar

1. Leia as aulas.
2. Faça os [exercícios](exercicios.md) — muitos são **refatorações**.
3. Confira as [soluções](solucoes/).
4. Passe no checkpoint.

## Checkpoint

1. Refatore 3 anti-patterns do seu código para a forma idiomática.
2. Escreva um arquivo de teste (`kof test`) com 10 asserts.
3. Leia config com `kof.config` e logue com `kof.log`.

`kof test` passando → trilha concluída.
